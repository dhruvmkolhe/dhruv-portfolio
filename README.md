
# Dhruv Kolhe

Personal developer portfolio built with React, TypeScript, Vite, and Motion.

## 🛠️ Stack

- **Core**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Motion (Framer Motion)

## 🚀 Development

```bash
# Install dependencies
npm install

# Start local server
npm run dev

# Build for production
npm run build
```
